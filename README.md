# Project Cadastral Cauayan (CaCau)
An open-source technical project that aims to fix discrepancies and correct the official boundaries of the barangays of Cauayan City published by the Cauayan City Planning and Development Coordinators' Office.

**DISCLAIMER: This project does not intend to put any negativity towards the Cauayan City Planning and Development Coordinators' Office.**

## Main Files
To effectively understand the project, these files are recommended to be inspected:

The Discrepancy Catalog shows all of the discrepancies that were identified through extensive research.

The Cauayan Weather file shows the risk of rain throughout the most of the rainy season since 2025.
